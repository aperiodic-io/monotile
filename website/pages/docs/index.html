Getting started

Your first five minutes

Install brrrrr, query a file of trades, build bars, join trades to quotes, and serve a live view. Every command on this page runs as written.

Install

You wantRun
Python (SQL shell included)pip install brrrrr

The Python package installs brrrrr-sql, a shell with the same SQL. The binary is brrrrr; brrrrr sql is its shell, and brrrrr serve its server. Examples below use the binary; with pip, write brrrrr-sql where they say brrrrr sql (it takes a statement, or -f file.sql; to write a file, use COPY).

Some data

The examples use three small files from the repository: half an hour of trades and quotes for BTC, ETH and SOL, and a table of instruments. Download them, or query them straight from GitHub: brrrrr reads https:// URLs as it reads files.

$ for f in trades quotes instruments; do
    curl -sO https://raw.githubusercontent.com/aperiodic-io/monotile/main/fixtures/cookbook/$f.csv
  done

A first query

A file in quotes is a table. Its columns and their types are read from the file; times in text are read as times.

$ brrrrr sql "DESCRIBE 'trades.csv'"
┌────────┬───────────┐
│ column │ type      │
├────────┼───────────┤
│ ts     │ timestamp │
│ symbol │ varchar   │
│ price  │ double    │
│ size   │ double    │
│ side   │ varchar   │
└────────┴───────────┘
$ brrrrr sql "SELECT symbol, count(*) AS trades, vwap(price, size) AS vwap
              FROM 'trades.csv' GROUP BY symbol ORDER BY symbol"
┌────────┬────────┬─────────────┐
│ symbol │ trades │ vwap        │
├────────┼────────┼─────────────┤
│ BTC    │    827 │ 42202.06861 │
│ ETH    │    887 │ 2300.399444 │
│ SOL    │    851 │ 98.67539508 │
└────────┴────────┴─────────────┘
3 rows

The same works for Parquet and JSON lines, for gzipped CSV, for a glob ('data/*.parquet'), for a directory of Hive partitions ('trades/' holding date=2024-01-02/…), and for s3://, gs://, az:// and https:// URLs. Files and object stores has the details.

Bars

time_bucket puts each row in its bucket of time, and first and last take the value at the earliest and latest time in it. Run SQL like this in the shell (brrrrr, then paste it), or save it as bars.sql and run brrrrr sql -f bars.sql:

SELECT time_bucket('1m', ts) AS minute, symbol,
       first(price, ts) AS open, max(price) AS high, min(price) AS low,
       last(price, ts) AS close, sum(size) AS volume
FROM 'trades.csv'
GROUP BY minute, symbol
ORDER BY minute, symbol
LIMIT 4;

│ minute              │ symbol │ open       │ high       │ low        │ close      │ volume  │
├─────────────────────┼────────┼────────────┼────────────┼────────────┼────────────┼─────────┤
│ 2024-01-01 00:00:00 │ BTC    │ 42004.1925 │ 42015.8896 │ 41780.2397 │ 41780.2397 │ 18.1991 │

Bucket widths are written '1m', '5 minutes', '1h' or INTERVAL '1 day'. Write the result to a file with -o, its format from its name, or with COPY (to an s3:// URL as well):

$ brrrrr sql -f bars.sql -o bars.parquet
$ brrrrr sql "COPY (SELECT * FROM 'trades.csv' WHERE symbol = 'BTC') TO 'btc.parquet'"

Trades against quotes

An ASOF JOIN pairs each trade with the last quote of its symbol at or before it: the market the trade met. From there, slippage is arithmetic.

SELECT t.ts, t.symbol, t.side, t.price, q.bid, q.ask,
       (t.price - (q.bid + q.ask) / 2) / ((q.bid + q.ask) / 2) * 1e4 AS slippage_bps
FROM 'trades.csv' t
ASOF JOIN 'quotes.csv' q ON t.symbol = q.symbol AND t.ts >= q.ts
ORDER BY t.ts
LIMIT 5;

ASOF LEFT JOIN keeps the trades with no quote before them. Snowflake's MATCH_CONDITION spelling works too.

From Python

import brrrrr

bars = brrrrr.sql("""
    SELECT time_bucket('5m', ts) AS t, symbol, vwap(price, size) AS vwap
    FROM 'trades.csv' GROUP BY t, symbol ORDER BY t, symbol
""")
bars.show()      # prints a table
df = bars.pl()   # or .df() for pandas, .arrow() for pyarrow

A Polars, pandas or pyarrow table in a variable is queried by its name. See Python.

Live

brrrrr serve holds live tables: rows written now are queried at once, with their history, and a live view keeps a query's answer as rows arrive.

$ brrrrr serve --data ./data &
$ curl -s -X POST 'localhost:4242/write/trades?format=csv' --data-binary @trades.csv
{"table":"trades","rows":2565}
$ curl -s -X POST localhost:4242/query --data "CREATE LIVE VIEW bars AS
    SELECT time_bucket('1m', ts) AS minute, symbol, last(price, ts) AS close, sum(size) AS volume
    FROM trades GROUP BY minute, symbol"
$ psql -h localhost -p 5433 -c "SELECT * FROM bars ORDER BY minute DESC LIMIT 3"

Open http://127.0.0.1:4242 for the console. The server guide covers Kafka ingest, subscriptions, tokens and Grafana.
