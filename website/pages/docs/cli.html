Reference

Command line

brrrrr on its own opens the SQL shell. brrrrr sql runs statements from its argument, a file or standard input. brrrrr serve and brrrrr run are the server and pipelines.

brrrrr sql

$ brrrrr sql "SELECT count(*) FROM 'trades.parquet'"     # one statement
$ brrrrr sql -f report.sql                               # statements from a file
$ cat report.sql | brrrrr sql                            # or from standard input
$ brrrrr sql                                             # the shell
OptionDoes
-f, --file FILERuns the statements of a file, ;-separated.
-t, --table NAME=LOCATIONNames a location as a table, as often as needed: -t trades=s3://b/trades/ -t quotes=quotes/*.parquet.
--format table|csv|json|parquetHow results are written. A table on a terminal, CSV into a pipe or file. json is one object per line.
-o, --output PATHWrites the last statement's result to a file or object store, its format from its name.
--threads NThreads per query; every CPU's by default.
--max-rows NRows a table shows at most (its first and last halves); 40 by default.

A failing statement prints its reason on standard error and the command exits with status 1, so scripts and CI stop on errors.

In pipes

$ brrrrr sql "SELECT * FROM 'trades.parquet' WHERE symbol = 'BTC'" | head
$ brrrrr sql --format json "FROM 'events.jsonl' LIMIT 3" | jq .
$ brrrrr sql --format parquet "FROM 'big.csv.gz'" > big.parquet

The shell

Statements end with ; and may span lines: Enter before the ; goes on to the next line, and the arrows edit the whole statement. Tab completes keywords, functions, tables and views, the columns of the tables a statement names, and inside quotes the data files and directories of the working directory. Ctrl+C stops a running query (the shell stays); on a line being typed, it clears it. History is kept in ~/.brrrrr_history.

CommandDoes
.tablesLists the tables and views named so far.
.mode table|csv|jsonHow results are shown.
.timer on|offShows each statement's time (on).
.read FILERuns the statements of a file.
.rows NRows a table shows at most.
.help, .quitHelp; leave (also Ctrl-D).
