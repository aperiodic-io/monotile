Three ways in

Point it at the files you already have

From the shell

brrrrr sql runs a query over a file, a glob, a Hive-partitioned directory or a bucket, and prints a table, CSV or JSON, or writes Parquet. No load step, no schema, no server.

Command line reference

$ brrrrr sql "
  SELECT symbol, count(*) AS trades, vwap(price, size) AS vwap
  FROM 's3://my-bucket/trades/date=2024-01-*/*.parquet'
  GROUP BY symbol ORDER BY trades DESC"

From Python

Results go to Polars, pandas and pyarrow through the Arrow C stream interface. A DataFrame in a variable is a table by its name.

Python guide

import brrrrr, polars as pl

trades = pl.read_parquet("trades.parquet")
bars = brrrrr.sql("""
    SELECT time_bucket('5m', ts) AS t, symbol,
           vwap(price, size) AS vwap, sum(size) AS volume
    FROM trades GROUP BY t, symbol
""").pl()

As a server

brrrrr serve keeps today's rows in memory and the rest in Parquet by day, and answers one query over both. HTTP with a browser console, the PostgreSQL protocol for psql, Grafana and every driver, and subscriptions.

Server guide

$ brrrrr serve --data ./data &
$ curl -X POST 'localhost:4242/write/trades?format=csv' --data-binary @trades.csv
$ curl -X POST localhost:4242/query --data "CREATE LIVE VIEW bars AS
    SELECT time_bucket('1m', ts) AS minute, symbol, last(price, ts) AS close
    FROM trades GROUP BY minute, symbol"
$ psql -h localhost -p 5433 -c "SELECT * FROM bars ORDER BY minute DESC LIMIT 5"

The cookbook

The queries people actually run

Each recipe runs in CI against the same files in DuckDB, and must give the same answer.

OHLCV bars

Candles from trades at any width: time_bucket, first, last.

SELECT time_bucket('1m', ts) AS minute, symbol,
  first(price, ts) AS open, last(price, ts) AS close
FROM 'trades.parquet' GROUP BY minute, symbol

Transaction costs

Every trade against the quote it met, with an exact as-of join.

SELECT t.*, (t.price - (q.bid + q.ask) / 2) AS slip
FROM trades t ASOF JOIN quotes q
  ON t.symbol = q.symbol AND t.ts >= q.ts

Volatility and risk

Returns, realized volatility, drawdowns, z-scores over rolling windows.

SELECT ts, price / lag(price) OVER w - 1 AS ret
FROM trades
WINDOW w AS (PARTITION BY symbol ORDER BY ts)

Order flow

Buy and sell volume, imbalance and volume profiles with FILTER.

SELECT symbol,
  sum(size) FILTER (WHERE side = 'buy') AS bought
FROM trades GROUP BY symbol

Data quality

Gaps in a feed, duplicates, and downsampling for a chart.

SELECT ts, ts - lag(ts) OVER w AS gap
FROM quotes
WINDOW w AS (PARTITION BY symbol ORDER BY ts)

Sensors and operations

Counter rates, latency percentiles, anomalies and sessions.

SELECT time_bucket('1m', ts) AS minute,
  quantile_cont(latency_ms, 0.99) AS p99
FROM readings GROUP BY minute

Markouts

Where the mid went 1, 5 and 60 seconds after each trade: as-of joins at a time offset.

ASOF JOIN quotes q5 ON t.symbol = q5.symbol
  AND t.ts + INTERVAL '5 seconds' >= q5.ts

Gap filling

Every minute shown, the last price carried into the empty ones.

SELECT time_bucket_gapfill('1m', ts) AS minute,
  locf(last(price, ts)) AS close
FROM trades GROUP BY minute

Time zones

Days and hours of any zone, daylight saving included.

SELECT time_bucket('1 day', ts, 'America/New_York')
  AS day, last(price, ts) AS close
FROM trades GROUP BY day
